========================================================================
ARIF ORGANIC FARM - IMAGES & ASSET DIRECTORY
========================================================================

This folder is designated for local image assets for the Arif Organic Farm website.

IMAGE ASSET CATEGORIES:
1. Produce (vegetables, fruits, organic eggs, honey, spices)
2. Farmland (lush green terraces, rich soil, sunrise over fields)
3. Farming Practices (bio-composting, heirloom seeding, drip irrigation, harvesting)
4. Farmers & Team (farm founders, agricultural experts, field harvesters)
5. Agro-Tourism & Farm Tours (visitors, workshops, farm gate market)

NOTE ON IMAGE LOADING:
The website is pre-configured with high-resolution, reliable CDN organic farm
photography from Unsplash with optimized WebP/JPG compression and responsive sizing.

If you wish to replace any imagery with your own custom camera photos, simply place
the image files into this directory (e.g. images/tomatoes.jpg, images/farm-hero.jpg)
and update the corresponding `src="images/your-image.jpg"` in the HTML files.

Recommended Image Dimensions:
- Hero / Page Headers: 1920x1080px (Landscape)
- Product Cards: 600x450px (4:3 aspect ratio)
- Process & Feature Cards: 800x600px
- Gallery Items: 800x600px / 1200x800px (High Definition)
- Team Avatars: 400x400px (Square 1:1)
